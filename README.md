# Verify Frozen Artifacts public demo

This repository is a public dogfood example for the `verify-frozen-artifacts` GitHub Action.

The workflow checks that `artifacts.sha256` still matches the artifact bytes in this repository.

- Tool: https://github.com/wu350891451-jpg/verify-frozen-artifacts
- Action: `wu350891451-jpg/verify-frozen-artifacts@v0.2.0`
